# Leaderboard Object Artwork

The dedicated leaderboard uses isolated product PNGs with alpha transparency.
These are similar objects to the user's supplied pack artwork, not the pack cards.
The homepage continues to use its original artwork.

- `leaderboard-sports-car.png`: blue Lamborghini Revuelto, sourced from
  [Sprint Filter](https://blog.sprintfiltershop.com/sprint-filter-presents-the-brand-new-air-filters-for-lamborghini-revuelto/).
  Original: https://blog.sprintfiltershop.com/wp-content/uploads/2025/04/11068be2-681d-8a5c-a530-92756a472a8e-1.png
- `leaderboard-watch.png`: Richard Mille RM 30-01, sourced from the manufacturer's
  [collection website](https://www.richardmille.com/collections).
  Original: https://media.richardmille.com/wp-content/uploads/2023/07/27125834/richard-mille-rm-30-01-declutchable-rotor-91234.png
- `leaderboard-diamond.png`: diamond cutout from
  [PNGimg, image 6692](https://pngimg.com/image/6692).
  Original: https://pngimg.com/uploads/diamond/diamond_PNG6692.png

  [PNGimg, image 101018](https://pngimg.com/image/101018).
